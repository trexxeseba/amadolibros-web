## Duplicación de catálogo

Script: `scripts/seo/duplication-report.mjs`.

Fuentes públicas, sin credenciales:

- `catalog.json` de R2;
- `catalog/manifest.json`;
- índice activo R2 actual;
- índice pausado R2 actual.

El reporte agrupa los activos por:

1. ISBN normalizado;
2. título + autor normalizados.

`same_book` significa **candidato a revisión**, no autorización automática para canonical/301. La decisión posterior debe considerar edición, editorial, idioma, formato, condición y diferencias comerciales cuando esos datos existan.

Los valores históricos mencionados previamente (3.201 grupos ISBN, ~1.037 candidatos mismo libro, ~2.164 ISBN inconsistentes y 194 grupos título+autor) se usan sólo como control de plausibilidad hasta reproducirlos con el script.

Ejecución:

```bash
SEO_OUTPUT_DATE=2026-08-08 \
SEO_OUTPUT_DIR=docs/seo/baseline-2026-08-08 \
node scripts/seo/duplication-report.mjs
```
