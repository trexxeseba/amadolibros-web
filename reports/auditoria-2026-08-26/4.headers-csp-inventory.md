# Bloque 4 — inventario de orígenes externos para CSP

BRIEF-AUDITORIA-EXTERNA-25AGO2026, Lote 3. **No es una policy, es el
inventario que el brief pide entregar antes de escribir cualquier
`Content-Security-Policy`.** Construido rastreando el HTML servido desde el
código fuente (no con una petición HTTP real: el entorno donde se hizo esta
auditoría no tiene salida de red hacia ningún host externo — ver
INFORME.md). Cada fila cita el archivo y la línea donde se genera el tag o
la llamada real, para que sea verificable sin confiar en esta lista a
ciegas.

## Llamada server-side que NO necesita entrar en la CSP

`www.google-analytics.com` (Measurement Protocol de GA4) se llama desde
`functions/api/_ga4_measurement.js`, **en el Worker, no en el navegador**. La
CSP del navegador no gobierna llamadas servidor-a-servidor — no corresponde
ninguna entrada por esto.

## Qué falta para escribir la policy (fuera de este Bloque)

1. Confirmar con Seba si Cloudflare Web Analytics/Insights está activo en el
   proyecto de Pages.
2. Confirmar con una ficha real (no alcanzable desde este entorno) si mlstatic
   llega a aparecer alguna vez en un `<img src>` real.
3. Desplegar la policy candidata como `Content-Security-Policy-Report-Only`
   en Preview primero, y revisar los reportes de violación antes de aplicarla
   en `Content-Security-Policy` real. El brief lo pide explícitamente y este
   Bloque no lo hace.
